# نَقْلِي (Naqli) — Saudi Moving Lead Gen

Brand: **نَقْلِي / Naqli** · Niche: نقل عفش · City focus: جدة  
Model: Google Ads → form/WhatsApp → sell leads to movers

## Localhost

```bash
cd /Users/ayoub/Desktop/COD/naqli-leads
npm run dev -- -p 3002
```

- Site: http://localhost:3002  
- Admin: http://localhost:3002/admin  
- Login: `admin` / `naqli2026`

بدّل رقم الجوال/واتساب في `lib/config.ts`.

## Deploy Netlify

1. New site from Git → repo `naqli-leads`
2. Build: auto via `netlify.toml` (`@netlify/plugin-nextjs`)
3. بعد الدبلوي بدّل رقم واتساب في `lib/config.ts` وادفع commit
